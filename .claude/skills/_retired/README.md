# Retired skills — archived so their deletion is reversible

`matchlens-flagged-moments` and `matchlens-pass-network` were retired along with
the standalone flagged-moments and pass-network reports. Flagged moments are now
reported inside the tactical and opposition reports where they are relevant.

**Only the unique content is kept here** — each skill's `SKILL.md` and its
example input/output. Everything else those skills contained (`render.py`,
`viz.py`, `brand.css`, all seven fonts) is byte-identical to the copies under
`matchlens-tactical-report/` and `matchlens-opposition-report/`, so nothing is
lost by not duplicating it a third and fourth time.

These directories are **not active skills** — the leading underscore keeps them
out of skill discovery. They exist so that deleting the originals from the
account-level store cannot lose anything.

Delete this folder once you are satisfied you will not want them back.
